# Malfoid Study

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
User delegated stack choice and approved lightweight HTML/CSS/JavaScript with a local server. Use native ES modules and Node.js HTTP serving, without runtime package dependencies.

## Users
The user is revising SC2001 algorithms and SC2005 operating systems for examinations using their existing long-form Malfoid explanations and 390 practice questions from Weeks 1-7.

## Product Purpose
Organise the existing complete explanations and make every topic available as an interactive MCQ quiz with clear feedback.

## Operating Context
Local personal study, with existing videos stored alongside the project. The app must work on desktop and mobile browsers. Cross-device synchronisation and public deployment are not requested.

## Capabilities and Constraints
Preserve existing videos; use the current complete revisions rather than short social clips. Include all 30 topics / 390 MCQs (4 Easy, 4 Medium, 4 Hard and 1 Baka per topic), graph diagrams, explicit trace conventions, difficulty levels, answer explanations and source references. Show answers after submission. Browser-local progress is an implementation assumption; expose its limits honestly. Quiz test scope explicitly confirmed: locking, scoring, retrying missed questions, saved progress; browser navigation and playback.

## Brand Commitments
Simple, minimalistic, well-designed, like Apple's website. Keep the existing Malfoid character and explanation content. The user refers to these as Malfoy explanations; the supplied assets are named Malfoid.

## Evidence on Hand
41 published SC2005 videos through Week7 plus18 existing complete SC2001 video lessons (16 in edit/series/complete-weeks01-07/library.json plus insertion sort and merge sort), current revisions and timestamped narration. Quiz source: tmp/pdfs/sc2001-mcq/bank.json, validated against the PDF. No testimonials or invented performance claims.

## Product Principles
- Watch the explanation, then practise the exact topic.
- Make intermediate algorithm states and diagrams easy to read.
- Keep navigation quiet and the lesson content prominent.
- Preserve source provenance and honest course conventions.
